# 🎯 Number Guessing Game

This is one of my first Python projects while learning with Harvard's CS50P course.

The game picks a random number between **1 and 100**, and your goal is to guess it. After every guess, you'll get a hint telling you if your guess was too high or too low until you find the correct number.

## Features

- Random number every game
- Tells you if your guess is too high or too low
- Counts how many guesses it took
- Handles invalid input so the program doesn't crash

## How to Run

Clone the repository:

```bash
git clone https://github.com/Nisarahmed-Hidayeti/python-number-guessing-game.git
```

Go into the project folder:

```bash
cd python-number-guessing-game
```

Run the game:

```bash
python number_guessing.py
```

## Example

```text
Guess a number (1-100): 50

Guess a number (1-100): 75

Guess a number (1-100): 68
```
